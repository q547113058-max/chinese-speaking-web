# 2026-06-10 Dev Log

## Scoring latency fix

- Added separate timeout controls:
  - `AI_SCORE_TIMEOUT_MS=3500` for scoring and vision requests.
  - `AI_CHAT_TIMEOUT_MS=12000` for normal chat and persona generation.
- Changed speaking `audio` scoring to return local acoustic feedback immediately from the uploaded PCM recording.
- Kept speaking `transcript` mode on the STT plus text scoring path.
- Changed Writing default scoring mode to local `stroke` scoring.
- Kept Writing `ai` mode available, but it now falls back to stroke scoring when the vision request fails or exceeds the scoring timeout.
- Added fallback handling for `/api/speaking/dialogue` so model timeouts return a usable roleplay response.
- Fixed `scripts/sync-github.ps1` to treat GitHub Contents API 404 as "new file" instead of stopping the sync.
- Removed learner-facing numeric scoring and radar charts from the frontend. Speaking, handwriting, sentence practice, and scene practice now show completion/self-check feedback and no longer call scoring APIs during normal use.
- Simplified Writing handwriting modes to `临摹` and `自由书写`; removed the learner-facing `AI 参考` mode.
- Removed the Writing `完成检查` button and its dead frontend handler; handwriting now uses undo, clear, and save as the only direct actions.
- Removed Writing `保存` and `自由书写`; handwriting now stays in trace-copy mode with undo and clear only.
- Applied the local `dw-skills`/`frontend-design` UI checklist across chat/listen/speak/read/write on desktop and mobile: no horizontal overflow, no clipped controls, no removed scoring/save/free-write text, and consistent Luming branding.
- Added a local-state migration that filters the old Su Tang greeting from stored conversation history.
- Changed Listening default to `场景辨别`; `声调辨别` now supports both button choice and voice answer, with STT plus Qwen3.6-Flash/chat-model feedback and local fallback.
- Changed Speaking default to `场景对话` and Reading default to `场景阅读` so scene-based practice is the first entry point for both skills.
- Expanded listening scene dialogues to at least 50 Chinese characters and fixed transcript hiding so text/pinyin stay hidden until the learner clicks `查看文本和拼音`.
- Expanded Reading into the seven-layer character flow, added pinyin spelling playback such as `j ing 敬`, click-to-hear Hanzi meanings, idiom background/explanation playback, three example-sentence follow-read prompts, and manual basic/advanced scene reading.
- Switched local chat feedback config to DashScope/Qwen3.6-Flash while leaving MiniMax as the TTS provider; `.env.example` now reflects the Qwen-compatible chat endpoint with placeholder key only.
- Verified Speaking content correctness paths: `/api/speaking/evaluate` returns `correctness` for voice shadowing, and `/api/speaking/dialogue` returns `correctness` for spoken scene replies.
- Fixed Speaking scene-dialogue correctness fallback: it now accepts `text`, `userText`, `transcript`, or `choice`, compares free-form replies with preset choices plus the shadow target and role task, and keeps unrelated replies marked incorrect.
