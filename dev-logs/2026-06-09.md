# 2026-06-09 Development Log

## Task

Implement the first version of speaking and writing practice on top of the current Mandarin conversation coach.

## Changes

- Extended `/api/practice` so every coach reply includes an `exercise` object with speaking and writing targets.
- Added `POST /api/speaking/evaluate` with transcript scoring and an audio-mode fallback to transcript scoring.
- Added `POST /api/writing/evaluate` with self-check scoring and an AI/OCR fallback path.
- Added a frontend skill practice panel with `说` and `写` tabs.
- Revised the frontend layout so `聊`, `说`, and `写` are mutually exclusive workspace modes instead of simultaneously visible chat and skill panels.
- Added speaking target playback, shadowing recording, radar scores, and feedback rendering.
- Added Canvas handwriting with trace text, undo, clear, save, and writing score rendering.
- Persisted the latest 20 speaking/writing practice results in `localStorage["chinese-speaking-coach-state"]`.
- Updated README, project docs, and changelog for the new APIs and UI.
- Added first-pass reading/listening practice: reading is Hanzi-pinyin matching, listening is tone selection, both scored locally and stored in the latest 20 skill results.
- Updated listening practice to show the current Hanzi while the learner plays audio and chooses the tone.
- Fixed speaking practice pinyin cropping so the displayed pinyin matches the displayed Chinese target sentence.
- Replaced the speaking audio-mode placeholder with first-pass acoustic scoring over the uploaded 16 kHz PCM recording. Audio mode now returns `modeUsed: "audio"` with duration, voiced speech ratio, pause, loudness, and rhythm metrics, while transcript mode stays text-based.
- Connected handwriting AI scoring to an OpenAI-compatible vision adapter. `/api/writing/evaluate` now uses `VISION_API_KEY`/`VISION_BASE_URL`/`VISION_MODEL` for `mode=ai`, falls back through existing `CHAT_*`/`OPENAI_*` config, returns `modeUsed: "ai"` with writing radar scores and optional recognized text, and keeps `self-fallback` plus `fallbackReason` when vision is unavailable.
- Expanded the app into a Luming scenario skill system with five built-in courses, course selection, second-level modes for listening/speaking/reading/writing, scene listening questions, speaking roleplay, seven-layer character cards, scene reading, sentence scoring, stroke-order handwriting scoring, and ink particle completion feedback.
